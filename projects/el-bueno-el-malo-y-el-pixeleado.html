Desarrollo de Videojuegos C++

El Bueno, El Malo y El Pixeleado

Videojuego de disparos arcade multijugador local en consola pura C++, diseñado para dos jugadores compitiendo simultáneamente en una matriz dinámica de 8x8 dentro del mismo teclado.

C++11 / C++17 std::thread std::chrono Matriz Dinámica Controlador de Consola
Ver en GitHub ↗

¿Qué hace el proyecto?

El Bueno, El Malo y El Pixeleado es un juego shooter táctico retro que demuestra el poder de la algoritmia básica y la programación estructurada en C++ sin depender de motores gráficos ni librerías pesadas externas.

Multijugador Local en el Mismo Teclado

Dos jugadores controlan sus personajes en tiempo real (Jugador 1 con WASD y Jugador 2 con Teclas de Dirección) para moverse y disparar proyecciones.

Matriz Dinámica 8x8

Representación matricial en consola que actualiza la posición de los jugadores, los obstáculos del terreno y la trayectoria de los proyectiles.

Sistema de Colisiones y Salud

Cálculo estricto de puntos de vida (HP) de cada combatiente con retroalimentación inmediata en la consola.

Game Loop Multihilo

Gestión de tiempos de refresco con std::this_thread::sleep_for para mantener una velocidad constante de movimiento y render.

¿Cómo lo construí?

Desarrollado puramente en C++ nativo con soporte multiplataforma (Windows cls / Linux clear): 


// Renderizado de la matriz de juego en C++
void em(string tablero[8][8], int renglones, int columnas, int v1, int v2) {
    for (renglones = 0; renglones < 8; renglones++) {
        for (columnas = 0; columnas < 8; columnas++) {
            cout << tablero[renglones][columnas];
        }
        cout << "\n";
    }
    cout << "\nVida Jugador 1: " << v1;
    cout << "\nVida Jugador 2: " << v2;
}
