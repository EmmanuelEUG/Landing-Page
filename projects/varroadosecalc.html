VarroaDoseCalc — Calculadora de Tratamientos contra Varroa

Aplicación Android nativa en Kotlin y Jetpack Compose que calcula automáticamente la dosis exacta de acaricidas para el control de Varroa destructor en colmenas, según las regulaciones sanitarias y el peso bruto de cada colmena.

Android Studio Kotlin Jetpack Compose Material Design 3 ViewModel StateFlow
Ver en GitHub ↗

¿Qué hace el proyecto?

VarroaDoseCalc nació de una necesidad real en el campo apícola. La Varroa destructor es el parásito más devastador para las colonias de abejas a nivel mundial, y su tratamiento debe ser preciso: una dosis insuficiente no elimina el parásito y una sobredosis puede dañar a las abejas o contaminar la miel.

Cálculo Preciso de Dosis

Determina la cantidad exacta de principio activo (ácido oxálico, timol, ácido fórmico u otros) según el peso registrado de la colmena y el método de tratamiento seleccionado.

Múltiples Métodos de Tratamiento

Compatible con los métodos más usados a nivel global: goteo sublimación, bandas acaricidas y vaporizadores de ácido oxálico.

Guía Estacional de Aplicación

Sugiere el momento óptimo de tratamiento según la época del año, el ciclo de cría de la colonia y el nivel de infestación estimado.

Historial de Aplicaciones

Registro de tratamientos anteriores por colmena para llevar una bitácora sanitaria completa del apiario.

¿Cómo lo construí?

Arquitectura MVVM con Jetpack Compose en un diseño completamente reactivo y desacoplado de la UI:

1. Modelo de Dominio y Lógica de Cálculo:

El TreatmentMethod.kt encapsula cada método de tratamiento como un objeto tipado con su fórmula de cálculo, límites de dosificación mínimos y máximos, y unidades de medida. El VarroaDoseCalcViewModel expone el cálculo al Composable a través de StateFlow. 


// TreatmentMethod.kt — Objeto de método de tratamiento
sealed class TreatmentMethod(
    val name: String,
    val unit: String
) {
    data object OxalicAcidDrip : TreatmentMethod("Ácido Oxálico (Goteo)", "ml")
    data object OxalicAcidSublimation : TreatmentMethod("Ácido Oxálico (Sublimación)", "g")
    data object Thymol : TreatmentMethod("Timol", "g")

    fun calculateDose(hiveWeightKg: Double): Double = when (this) {
        is OxalicAcidDrip -> hiveWeightKg * 0.5      // 0.5 ml / kg de colmena
        is OxalicAcidSublimation -> 2.0               // 2g fijos por tratamiento
        is Thymol -> hiveWeightKg * 0.3
    }
}

2. UI Declarativa con Material Design 3:

La pantalla principal (VarroaDoseCalcScreen.kt) usa componentes de Material 3 como OutlinedTextField, DropdownMenu y ElevatedCard con transiciones suaves de estado para mostrar el resultado del cálculo al instante.

3. Conexión directa con SAM:

Este proyecto complementa el ecosistema del sistema SAM al proporcionar la herramienta de campo que los apicultores usan directamente en su teléfono durante las inspecciones presenciales en el apiario.

Impacto Real

VarroaDoseCalc elimina los errores de cálculo manual que pueden comprometer la salud de una colonia completa. Al digitalizar la dosimetría de tratamientos, permite a los apicultores artesanales e industriales cumplir con las normativas sanitarias de la SENASICA (México) sin necesidad de conocimientos veterinarios avanzados.
