SAM - Smart Apiary Monitoring System

Plataforma integral de monitoreo IoT y gestión apícola con lectura de temperatura, humedad y peso en tiempo real, API RESTful en Javalin, backend Java multihilo, base de datos MySQL y dashboard web analítico.

Java 17 Javalin REST API ESP32 IoT MySQL JavaScript ES6 Chart.js BCrypt Auth
Ver en GitHub ↗

¿Qué hace el proyecto?

SAM (Smart Apiary Monitoring) es una solución agrotecnológica diseñada para la apicultura moderna. Las colmenas de abejas son extremadamente sensibles a variaciones de temperatura, humedad interna y fluctuaciones drásticas de peso (indicadores de enjambrzón o producción de miel).

SAM automatiza el flujo completo desde la captura de datos en el campo hasta la toma de decisiones empresariales:

Monitoreo Telemétrico IoT

Módulos ESP32 transmiten telemetría periódica de temperatura, humedad relativa y peso de cada colmena a través de HTTP/REST.

Analytics y Diagnóstico

Visualización gráfica interactiva con producción por colmena, métricas promedio por temporada y sistema de alertas por umbrales desfigurados.

Bitácora de Inspecciones

Gestión completa de visitas técnicas, registro de presencia de reina, estado sanitario del nudo y control de cosechas acumuladas.

Seguridad Avanzada de Sesiones

Autenticación mediante cookies de sesión HTTP-only, cifrado de contraseñas con BCrypt y control de acceso basado en roles.

¿Cómo lo construí?

Arquitectura desacoplada basada en microservicios ligeros con un backend estructurado en capas en Java + Javalin:

1. Backend y API RESTful:

Utilicé Javalin por su alto rendimiento e insignificante sobrecarga de memoria en comparación con frameworks tradicionales. El backend maneja controladores para autenticación, gestión de apiarios, lecturas de sensores, registros de inspección y cosechas. 


// Ejemplo de controlador Javalin para lecturas de sensores
app.get("/api/colmenas/{id}/lecturas", ctx -> {
    int colmenaId = Integer.parseInt(ctx.pathParam("id"));
    List<LecturaSensor> lecturas = sensorService.obtenerLecturas(colmenaId);
    ctx.json(lecturas);
});

// Autenticación segura con BCrypt y cookies de sesión
app.post("/api/auth/login", ctx -> {
    LoginRequest req = ctx.bodyAsClass(LoginRequest.class);
    User user = userService.authenticate(req.getUsername(), req.getPassword());
    if (user != null) {
        ctx.cookie("sam_session", user.getToken(), 86400); // 24h
        ctx.json(Map.of("status", "success", "role", user.getRole()));
    } else {
        ctx.status(401).result("Credenciales inválidas");
    }
});

2. Base de Datos Relacional Optimizada:

Diseñé el esquema relacional en MySQL indexando claves foráneas entre usuarios, apiarios, colmenas, lecturas_sensores y cosechas. Se crearon vistas agregadas para agilizar las consultas métricas en los dashboards.

3. Frontend Web Interactivo:

Construido con HTML5 semántico, CSS3 modular con variables personalizadas y JavaScript asíncrono (Fetch API). Utiliza Chart.js para renderizar curvas de temperatura y peso temporal en tiempo real.

Impacto y Resultados

SAM permite a los productores apícolas reducir hasta en un 40% las visitas de inspección física innecesarias a los apiarios, detectando problemas de salud en las colonias semanas antes de que sean irreversibles.
