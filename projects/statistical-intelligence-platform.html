Statistical Intelligence Platform (SIP)

Plataforma analítica ejecutiva híbrida full-stack para el procesamiento avanzado de datos estadísticos, renderización de dashboards ejecutivos dinámicos e integración en tiempo real entre Python/Streamlit y React.

Python 3.12 Streamlit React GSAP Animations Pandas Tailwind CSS
Ver Demo En Vivo GitHub ↗

¿Qué hace el proyecto?

Statistical Intelligence Platform (SIP) es un panel analítico interactivo diseñado para ejecutivos y científicos de datos que necesitan transformar datasets complejos en reportes estadísticos visuales y comprensibles.

Carga y Análisis Automatizado

Subida de datos masivos en CSV o Excel con limpieza instantánea, cálculo de varianza, promedios, correlaciones y distribución normal.

Dashboard con Animaciones GSAP

Interfaz ejecutiva con gráficos interactivos renderizados dinámicamente mediante React y efectos cinematográficos con GSAP.

Puente de Datos JSON Inyectado

Mecanismo eficiente de inyección directa de JSON (__SIP_DATA__) a tiempo de renderizado entre el motor de análisis en Python y la UI en React.

¿Cómo lo construí?

Arquitectura híbrida que conecta el poder del ecosistema científico de Python con la fluidez visual del desarrollo web moderno en React: 


# Fragmento del bridge de datos entre Streamlit y React
import streamlit as st
import json

def render_react_dashboard(dataframe):
    json_data = dataframe.to_json(orient="records")
    html_content = f"""
    <script>
        window.__SIP_DATA__ = {json_data};
    </script>
    <iframe src="./index.html" style="width:100%; height:800px; border:none;"></iframe>
    """
    st.components.v1.html(html_content, height=820)

Impacto y Despliegue

El proyecto se encuentra desplegado y accesible públicamente en la nube de Streamlit, sirviendo como herramienta de referencia para análisis rápido de datos en entornos académicos y corporativos.
