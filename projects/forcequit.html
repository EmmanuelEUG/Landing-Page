ForceQuit - Gestor de Cierre Forzado para Hyprland

Utilidad gráfica ultraligera en Python y PyQt6 diseñada específicamente para usuarios de ArchLinux y el compositor Wayland Hyprland, permitiendo finalizar procesos bloqueados de forma inmediata y limpia.

Python 3 PyQt6 Hyprland (hyprctl) psutil QSS / Custom CSS
Ver en GitHub ↗

💡 ¿Qué hace el proyecto?

ForceQuit soluciona un problema muy común en entornos de escritorio basados en Wayland y compositores de ventanas como Hyprland: cuando una aplicación gráfica se congela o deja de responder, las herramientas tradicionales xkill no siempre funcionan correctamente.

💻 Integración Nativa con Hyprland

Interactúa con la IPC de Hyprland utilizando hyprctl clients -j para listar únicamente ventanas gráficas activas en los espacios de trabajo.

💠 Terminación Limpia y Recursiva

Usa psutil.Process(pid).children(recursive=True) para eliminar el proceso padre y todos sus subprocesos hijos, evitando procesos zombi en la memoria.

🎨 Interfaz Moderada en PyQt6

Ventana flotante estilizada con QSS que coincide con la estética oscura de Linux Hyprland.

🔍 Identificación por PID

Muestra claramente el PID del sistema y la clase del cliente gráfico para evitar cerrar accidentalmente procesos equivocados.

🛠 ¿Cómo lo construí?

El script en Python 3 consulta la lista de ventanas activas llamando a la herramienta oficial hyprctl en formato JSON y renderiza dinámicamente un menú interactivo en PyQt6:

# Fragmento del cierre recursivo de procesos con psutil import subprocess, json, psutil def terminate_process_tree(pid): try: parent = psutil.Process(pid) children = parent.children(recursive=True) for child in children: child.kill() parent.kill() print(f"Proceso {pid} y sus subprocesos eliminados con éxito.") except psutil.NoSuchProcess: pass

🏆 Impacto

Proporciona a los usuarios de Hyprland una herramienta confiable con atajo de teclado para mantener el sistema ágil sin necesidad de abrir una terminal y ejecutar manualmente kill -9 o htop.
