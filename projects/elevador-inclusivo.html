Elevador Inclusivo con Control Gestual y de Voz

Sistema de transporte vertical inteligente y accesible para personas con discapacidad motriz o visual, controlado mediante reconocimiento de gestos con visión artificial y síntesis/reconocimiento de voz bilingüe.

Python 3.13 OpenCV MediaPipe PyQt5 Arduino / Serial SpeechRecognition pyttsx3 (TTS)
Ver en GitHub ↗

💡 ¿Qué hace el proyecto?

El Elevador Inclusivo es un prototipo tecnológico diseñado para eliminar las barreras de accesibilidad en edificios públicos y privados. Tradicionalmente, los paneles de botones de un elevador representan un obstáculo para personas con discapacidad visual o con movilidad limitada en brazos y manos.

Este sistema permite interactuar con el elevador sin necesidad de contacto físico mediante dos modalidades principales:

👋 Reconocimiento de Gestos

Detección en tiempo real de la mano y conteo de dedos (1 a 5) a través de una cámara web mediante IA visual para seleccionar el piso deseado.

🎥 Control de Voz Bilingüe

Comandos de voz procesados en español e inglés ("subir al piso 2", "open door") con respuesta de audio por síntesis de voz (Text-to-Speech).

💻 Interfaz Gráfica de Control

Dashboard de monitoreo desarrollado en PyQt5 que muestra el estado del elevador, la señal de cámara en vivo y los logs de comunicación.

👁 Feedback Accesible

Confirmación auditiva y visual de cada acción para que usuarios con ceguera o debilidad auditiva sepan exactamente a qué piso se dirigen.

🛠 ¿Cómo lo construí?

El proyecto integra un pipeline de software en Python coordinado con un controlador físico en Arduino a través de comunicación serial (USART/UART):

1. Procesamiento de Visión Artificial (MediaPipe + OpenCV):

Utilicé la biblioteca mediapipe.solutions.hands para rastrear 21 puntos de referencia (landmarks) en la mano en tiempo real a 60 FPS. Un algoritmo de geometría calcula la posición relativa de las yemas de los dedos respecto a las articulaciones metacarpofalángicas para determinar con exactitud cuántos dedos están levantados.

# Fragmento del cálculo de puntos de referencia con MediaPipe import mediapipe as mp import cv2 mp_hands = mp.solutions.hands hands = mp_hands.Hands(max_num_hands=1, min_detection_confidence=0.7) # Verificación de extensión de dedos def contar_dedos(hand_landmarks): dedos = [] # Pulgar if hand_landmarks.landmark[4].x < hand_landmarks.landmark[3].x: dedos.append(1) # Dedos índice, medio, anular, meñique for id in [8, 12, 16, 20]: if hand_landmarks.landmark[id].y < hand_landmarks.landmark[id - 2].y: dedos.append(1) return sum(dedos)

2. Interfaz y Arquitectura Multihilo (PyQt5):

Para evitar bloquear la interfaz de usuario mientras la cámara procesa fotogramas y la voz escucha instrucciones, separé las tareas pesadas en hilos independientes (QThread). El hilo principal administra la GUI y la renderización en pantalla.

3. Control de Hardware en Tiempo Real:

Los comandos validados se envían por el puerto serial (pyserial en COM3 / /dev/ttyUSB0 a 9600 baudios) hacia una placa Arduino que controla los motores paso a paso y los sensores del elevador.

🏆 Lecciones Aprendidas e Impacto

Este desarrollo demostró el inmenso potencial de combinar la visión por computadora y el procesamiento del lenguaje natural para crear soluciones inclusivas de bajo costo.

Aprendí a gestionar la latencia en algoritmos de visión por computadora, a manejar concurrencia en Python con PyQt5 y a estructurar protocolos de comunicación serial robustos contra errores de transmisión.
