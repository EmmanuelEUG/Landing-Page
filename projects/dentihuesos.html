Escritorio & Gestión Médica

DentiHuesos - Sistema de Gestión Odontológica

Aplicación de escritorio empresarial para la administración completa de un consultorio dental: expediente clínico de pacientes, control de citas, catálogo de tratamientos, stock de medicamentos e inventario médico.

C# .NET Framework Windows Forms MySQL Connector ADO.NET
Ver en GitHub ↗

¿Qué hace el proyecto?

DentiHuesos es un software de escritorio desarrollado a la medida para simplificar la operación diaria de clínicas odontológicas. Reemplaza las bitácoras físicas en papel por un sistema digital centralizado que optimiza la atención al paciente y la administración financiera.

Expediente Clínico de Pacientes

Registro detallado de datos personales, historial médico, alergias, diagnósticos y tratamientos realizados a cada paciente.

Control de Inventario y Medicamentos

Monitoreo en tiempo real del stock de insumos odontológicos y fármacos, alertando cuando los niveles están próximos a agotarse.

Agenda de Citas

Programación dinámica de consultas médicas por especialista con estados de confirmación, cancelación y asistencias.

Facturación y Cobros

Generación de notas de pago por servicios realizados y seguimiento del historial financiero de la clínica.

¿Cómo lo construí?

El proyecto está desarrollado en C# (.NET Framework) siguiendo una arquitectura multitapa (UI, Lógica de Negocio y Acceso a Datos):

1. Interfaz de Usuario (Windows Forms):

Diseñé una interfaz intuitiva organizada mediante formularios MDI (Multiple Document Interface) que permite a los asistentes y dentistas navegar rápidamente entre clientes, citas e inventario sin perder el contexto de trabajo.

2. Capa de Datos con MySQL & ADO.NET:

Implementé patrones de acceso a datos seguros utilizando MySqlCommand con parámetros para prevenir inyecciones SQL y garantizar la integridad transaccional de los expedientes médicos. 


// Ejemplo de consulta parametrizada en C# ADO.NET
using (MySqlConnection conn = new MySqlConnection(connectionString))
{
    conn.Open();
    string query = "INSERT INTO Pacientes (Nombre, Telefono, Historial) VALUES (@nombre, @telefono, @historial)";
    using (MySqlCommand cmd = new MySqlCommand(query, conn))
    {
        cmd.Parameters.AddWithValue("@nombre", txtNombre.Text);
        cmd.Parameters.AddWithValue("@telefono", txtTelefono.Text);
        cmd.Parameters.AddWithValue("@historial", txtHistorial.Text);
        cmd.ExecuteNonQuery();
    }
}
