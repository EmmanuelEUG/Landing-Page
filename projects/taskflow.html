TaskFlow - Gestor de Tareas de Alto Rendimiento

Aplicación de escritorio moderna construida con Electron, React, TypeScript y Tailwind CSS, diseñada para la gestión fluida de tareas diarias con analíticas visuales e integración multiplataforma.

Electron React 18 TypeScript Tailwind CSS Vite Recharts Electron Store
Ver en GitHub ↗

¿Qué hace el proyecto?

TaskFlow es un gestor de productividad personal y profesional diseñado para ofrecer una experiencia ultra fluida y rápida en sistemas Linux, macOS y Windows.

Organización Inteligente de Tareas

Categorización por proyectos, prioridades, etiquetas dinámicas y fechas límite con estados personalizables.

Gráficos y Métricas de Productividad

Visualizaciones interactivas impulsadas por Recharts para analizar el porcentaje de cumplimiento y horas dedicadas por categoría.

Almacenamiento Local Seguro

Persistencia inmediata offline usando Electron Store sin necesidad de conectarse a servidores externos.

Empaquetado Nativo

Compilado directamente como paquete ejecutable para Linux (AppImage / deb) y compatible con atajos globales del sistema.

¿Cómo lo construí?

Utilicé la arquitectura moderna recomendada para Electron con electron-vite para obtener compilaciones instantáneas (HMR):

1. Comunicación IPC Segura (Main vs Renderer):

El proceso principal de Electron (Main) y la interfaz en React (Renderer) se comunican a través de un puente seguro con contextBridge en el script de preload, respetando las mejores prácticas de seguridad de Electron. 


// preload/index.ts - Puente tipado en TypeScript
import { contextBridge, ipcRenderer } from 'electron';

contextBridge.exposeInMainWorld('api', {
    getTasks: () => ipcRenderer.invoke('tasks:get'),
    saveTask: (task) => ipcRenderer.invoke('tasks:save', task),
    deleteTask: (id) => ipcRenderer.invoke('tasks:delete', id)
});

2. Interfaz React Moderna con Tailwind CSS:

Diseño limpio y minimalistico aprovechando Tailwind CSS para un look responsivo, junto con iconos vectoriales de Lucide React y componentes altamente modulares.

Aprendizajes

Dominé la integración de React en entornos de escritorio con Electron, el manejo de TypeScript estricto en arquitecturas IPC y la optimización del rendimiento de renderizado en aplicaciones de escritorio basadas en Chromium.
