GasTour - Calculadora Inteligente de Rutas y Gasolina

Aplicación móvil Android nativa construida en Kotlin con Jetpack Compose para la planificación de viajes por carretera, estimación precisa de costos de combustible por vehículo, gestión de rutas favoritas y mapa interactivo.

Android Studio Kotlin Jetpack Compose Retrofit 2 StateFlow / ViewModel MapWebView TokenManager
Ver en GitHub ↗

💡 ¿Qué hace el proyecto?

GasTour es una solución de movilidad diseñada para conductores y viajeros que desean optimizar sus gastos de transporte. Al ingresar el origen, destino y el modelo de vehículo registrado, la aplicación calcula el rendimiento real de combustible (km/l), el volumen total de litros requeridos y el presupuesto financiero estimado para el viaje.

🚶 Planificación de Rutas y Mapa Interactivo

Visualización del trayecto optimizado a través de un componente de mapa integrado con geolocalización y cálculo de distancia.

🚗 Garaje de Vehículos Personalizado

Permite agregar múltiples vehículos especificando su rendimiento urbano/carretera y tipo de combustible (Magna, Premium, Diésel).

🔖 Historial de Rutas Guardadas

Almacena las rutas más frecuentes para una rápida reconsulta sin necesidad de volver a calcular datos.

🔒 Autenticación JWT y Perfil

Gestión de sesión segura con almacenamiento de tokens bearer, actualización de contraseña y sincronización en la nube.

🛠 ¿Cómo lo construí?

Arquitectura móvil basada en **MVVM (Model-View-ViewModel)** y diseño declarativo de interfaces con **Jetpack Compose**:

1. Capa de Red y API Rest (Retrofit 2 + OkHttp Interceptor):

Utilicé Retrofit junto con AuthInterceptor para inyectar automáticamente el token de autorización JWT en cada petición HTTP hacia la API de backend.

// TokenManager y AuthInterceptor en Kotlin class AuthInterceptor(private val tokenManager: TokenManager) : Interceptor { override fun intercept(chain: Interceptor.Chain): Response { val token = tokenManager.getToken() val request = chain.request().newBuilder() if (!token.isNullOrEmpty()) { request.addHeader("Authorization", "Bearer $token") } return chain.proceed(request.build()) } }

2. Interfaz Declarativa moderna (Jetpack Compose):

Toda la interfaz gráfica está programada en Compose puro con navegación basada en destinos (NavHost), StateFlow para la gestión reactiva del estado de la pantalla (AppUiState) y temas personalizados de Material Design 3.

🏆 Impacto

GasTour ayuda a los conductores a planificar viajes largos de forma inteligente, evitando sorpresas presupuestarias en las estaciones de servicio.
